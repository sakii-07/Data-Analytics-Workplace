Statistics : Statistics is the branch of mathematics used to collect, organize, analyze, interpret, and present data so that 
             meaningful insights can be extracted and decisions can be made.


1. Descriptive Statistics

Descriptive statistics is used to summarize, organize, and describe data.

        Measures of Central Tendency
            Mean (Average) -- don't use where there is extreme value
            Median (Middle value)
            Mode (Most frequent value)

    Mean → Average → Uses all values
    Median → Middle → Resistant to outliers
    Mode → Most common → Frequency-based

        Measures of Dispersion (Spread)
            Range
            Variance
            Standard Deviation

2. Inferential Statistics

Inferential statistics is used to make predictions or conclusions about a population using a sample.

    Common Techniques
        Hypothesis Testing
        Confidence Intervals
        Regression Analysis
        ANOVA
        Chi-Square Test
